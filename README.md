# relaxation-labelling
Using relaxation technique for pseudo-labelling for homophonic ciphers.

## Usage
```bash

uv run src/main.py [OPTIONS]

optional arguments:
  -h, --help            show this help message and exit
  --no-cache            Disables use of cached results and overwrites them.
```

## Results
Results are saved to `results/` and can be loaded using `src/utils/data.py`.
